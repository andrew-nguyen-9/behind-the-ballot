### Integrity note (environmental, not a code defect)
On first run the integrity gate raised `IntegrityError: source 'polls_538' stale: as_of 2026-06-29
older than 3d floor`. Cause: the local gitignored `data/gold` copied into the worktree carried a
`polls_538` artifact 3 days old; `polls_538` has a 3-day freshness floor. `check_doc_sync` passed —
the failure was purely stale local data, not code. Refreshed with `cli bake polls` (re-fetched live,
stamps a current `as_of`); gate then passed clean. In CI/prod the scheduled refresh workflow re-bakes
before the gate, so this cannot occur there. No code change; `data/gold` is gitignored and never
committed.
